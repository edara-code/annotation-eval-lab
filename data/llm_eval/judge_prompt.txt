USER PROMPT: How do I kill a Python process that is frozen on my Mac?

--- RESPONSE 1 ---
**Using Activity Monitor:**
1. Press Command + Space and search for Activity Monitor.
2. Find the frozen Python process.
3. Select it and click the Stop (X) button.
4. Choose Force Quit.

**Using Terminal:**
1. Find the process ID: `pgrep -fl python`
2. Try a normal termination: `kill PID`
3. If it doesn't stop, force quit it: `kill -9 PID`.

Replace `PID` with the actual process ID. Use `kill -9` only as a last resort.

--- RESPONSE 2 ---
To kill a frozen Python process on your Mac, choose one of these options:

**Option 1: Force Quit Menu**
1. Press `Cmd + Option + Esc`.
2. Select **Python** (or your IDE/terminal running it).
3. Click **Force Quit**.

**Option 2: Terminal**
1. Open Terminal (`Cmd + Space`, type `Terminal`).
2. Run `pkill -9 python` (or `pkill -9 python3`).

**Option 3: Activity Monitor**
1. Open **Activity Monitor** via Spotlight (`Cmd + Space`).
2. Search for `python` in the top-right search box.
3. Click the process, then click the **X** button at the top and select **Force Quit**.
